## 🧩 About Me

Computer Science Engineering student at Universidad del Valle de Guatemala. I build end-to-end applications — APIs in Go, interfaces in React/Vue, databases in PostgreSQL — and I'm increasingly drawn to what happens after the code works: how people actually use it, and what the data says about it.
